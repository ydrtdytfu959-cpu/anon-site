Agreed detail contract:
- Public GET `/catalog/channel3/products/{id}` with exact `option_<name>=<label>` query parameters; upstream locale fixed to US/USD/en.
- Envelope `{provider:'channel3',data:{product},fetchedAt,expiresAt,status,error,selectionMismatch}`. Product is the bounded, allowlisted official Product shape. `status` is `fresh` or `presentation_only`; mismatch entries are `{name,requested,effective}`.
- Browser `getChannel3Product(id,{options,signal})` returns separate `anox.product-detail/1` model; it bypasses the lossy card normalizer. See adapter tests for exact fields. Stock quantity remains null; purchase authorization remains false.
- Internal IAM-only Lambda event `{operation:'commerce.product',productId,options?}` accepts only these keys and no HTTP metadata. It must return a fresh envelope or a safe error. A public request cannot select the internal operation.
- Every PDP/reselection and internal quote obtains fresh upstream detail. One process coalesces concurrent calls. Distributed result exchange accepts only responses completed after that request began, never later visits. The exchange expires in 30 seconds.
- One-hour presentation fallback contains no prices, offers, or availability. Quote requests never use fallback. Gallery limit64 and payload limit256KiB reject oversized data rather than silently truncating.
- Offer identifiers are absent from official API. Preserve attributed URLs, domain and condition without fabricating an upstream ID. Buy URLs rotate and cannot be the persistent offer identity.
